# Child Malnutrition Risk Predictor — Pakistan
## SDG Alignment
SDG 2 — Zero Hunger: Specifically Target 2.2 — End all forms of malnutrition by 2030, including achieving internationally agreed targets on stunting and wasting in children under five.
## Problem Statement
Malnutrition in children under five is one of the most serious public health problems in Pakistan. The main challenge is that malnutrition is usually identified very late, after a child has already been severely affected, and the damage to their physical and cognitive development may have already become irreversible.\
This project aims to make a data driven tool available for community health workers by building a machine learning model trained on real Pakistani household survey data that can predict malnutrition risk and deliver the result through a simple web application that anyone can use.
## Dataset Description
Primary Dataset: UNICEF Multiple Indicator Cluster Survey (MICS) — Three Provincial Surveys\
Source: UNICEF MICS Programme (mics.unicef.org)\
Coverage: District representative samples across all three provinces
